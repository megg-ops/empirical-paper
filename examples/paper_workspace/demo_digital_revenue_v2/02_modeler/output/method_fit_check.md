# 方法-数据匹配检查

## 1. 数据结构判断
- 数据结构：截面数据（180 家企业，每家一期观测，无时间维度）
- 判断依据：firm_id 唯一值 = 180 = 总行数；无 year/date/period 等时间字段
- 是否支持推荐模型：是。OLS 是截面数据 + 连续因变量的标准方法

## 2. 因变量类型判断
- 因变量：revenue_growth_pct
- 类型：连续变量（范围 [-4.91, 19.46]，float64）
- 是否匹配推荐模型：是。OLS 适用于连续因变量

## 3. 识别条件判断
- 政策冲击：无
- 处理组/对照组：无
- 时间维度：无
- 断点：无
- 工具变量：无
- 固定效应：不适用（非面板数据）
- 结论：数据不具备任何因果识别条件，仅支持相关性分析

## 4. 推荐模型
- 模型：OLS 回归 + HC1 稳健标准误 + 行业/区域虚拟变量
- 适配理由：截面数据 + 连续因变量 + 相关性分析，OLS 是标准方法；HC1 应对异方差；虚拟变量控制行业和区域不可观测异质性
- 必要诊断：VIF（多重共线性）、Breusch-Pagan（异方差）、残差正态性

## 5. 不推荐模型

| 模型 | 不推荐原因 |
|---|---|
| DID | 无政策冲击、无处理组/对照组、无时间前后 |
| 固定效应/随机效应 | 非面板数据 |
| RDD | 无断点、无运行变量 |
| IV/2SLS | 无工具变量 |
| DEA/SFA | 非多投入多产出结构，研究目标非效率评价 |
| Logit/Probit | 因变量非二元 |
| Tobit | 因变量无截断/删失机制 |
| 系统GMM | 非动态面板数据 |

## 6. 解释边界
- 是否支持因果解释：否
- 允许使用的表述：
  - "数字化能力与营业收入增长率显著相关"
  - "数字化能力较高的企业往往具有更高的营业收入增长率"
  - "在控制相关变量后，二者之间的统计相关性仍然存在"
  - "回归结果显示二者具有统计相关性"
  - "方向与理论预期一致"
- 禁止使用的表述：
  - "数字化能力导致营业收入增长"
  - "数字化能力显著促进企业增长"
  - "数字化转型产生因果效应"
  - "政策效应"
  - "提升了/降低了"

## 7. Stage 2 判定

**PASS**

方法与数据匹配：截面数据 + 连续因变量 + 相关性分析 → OLS 是标准且适当的方法。所有识别条件（无政策冲击、无面板结构等）的缺失与相关性分析目标一致，不构成问题。解释边界已明确声明为相关而非因果。

## 8. 用户确认事项
1. 数据结构判断（截面数据）是否正确
2. 因变量类型判断（连续变量）是否正确
3. 推荐模型（OLS + 稳健标准误 + 行业/区域虚拟变量）是否匹配研究问题
4. 不推荐模型及原因是否接受
5. 模型不支持因果解释是否理解并接受
6. 是否存在用户知道但数据中未体现的政策冲击、分组、断点或工具变量
7. 是否确认按该模型进入 Stage 3 编码
