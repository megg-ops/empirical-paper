# 模型选择方案

## 0. 模型选择树定位

### 0.1 研究目标定位
- 判断：相关性分析
- 理由：研究框架明确提出"企业数字化能力是否与营业收入增长率存在显著相关关系"，且明确声明"只做相关性分析，不做因果识别"

### 0.2 数据结构定位
- 判断：截面数据
- 证据：180 行 × 13 列，每行代表一家企业，无时间维度字段，firm_id 唯一值 = 行数

### 0.3 因变量类型定位
- 判断：连续变量
- 证据：revenue_growth_pct 为 float64，范围 [-4.91, 19.46]，无截断/删失

### 0.4 识别条件定位
- 是否存在政策冲击：否
- 是否存在处理组/对照组：否
- 是否存在断点：否
- 是否存在工具变量：否
- 是否适合固定效应：否（非面板数据）
- 是否需要环境变量/投入产出结构：否（非效率评价）

### 0.5 内生性风险
- 遗漏变量：存在（如管理质量、市场环境等不可观测因素），已通过控制变量部分缓解
- 反向因果：可能（营收增长好的企业更有资金投入数字化），但因非因果研究目标，在结论中以局限声明即可
- 选择偏误：低（非样本选择模型）
- 动态内生性：不适用（无时间维度）
- 处理策略：使用稳健标准误（HC1）应对异方差；在结论中明确声明相关而非因果

### 0.6 候选模型集

| 模型 | 适配理由 | 数据要求 | 风险 |
|---|---|---|---|
| OLS + 稳健标准误 | 截面+连续Y+相关性分析的标准方法 | 截面数据，连续因变量 | 不支持因果解释 |
| OLS + 稳健标准误 + 行业/区域虚拟变量 | 控制行业和区域的不可观测异质性 | 同上 | 虚拟变量较多可能降低自由度 |
| 稳健标准误 OLS + 对数变换 employees | 降低大企业极端值影响 | employees > 0 | 解释变为弹性 |

### 0.7 最终推荐模型
- 推荐模型：OLS 回归 + 稳健标准误（HC1）+ 行业/区域虚拟变量
- 推荐理由：截面数据 + 连续因变量 + 相关性分析，OLS 是最匹配的方法；稳健标准误应对异方差；虚拟变量控制行业和区域不可观测异质性
- 可解释边界：仅支持相关性解释，不支持因果推断

### 0.8 不推荐模型

| 不推荐模型 | 不推荐原因 |
|---|---|
| DID | 无政策冲击、无处理组/对照组、无时间前后 |
| 固定效应 (FE/RE) | 非面板数据，无个体-时间二维结构 |
| RDD | 无断点、无运行变量 |
| IV/2SLS | 无工具变量 |
| DEA/SFA | 非效率评价目标，非多投入多产出结构 |
| Logit/Probit | 因变量非二元变量 |
| Tobit | 因变量无截断/删失机制 |
| 系统GMM | 非动态面板数据 |

## 1. 数据结构判断
- 类型：截面数据
- 判断依据：180 家企业各一期观测，无时间字段，firm_id 唯一值 = 180 = 总行数
- 优势：结构简单，适合经典 OLS
- 局限：无法控制企业固定效应，无法追踪时间变化，无法识别因果关系

## 2. 变量设定

### 被解释变量
- revenue_growth_pct：企业近一年营业收入增长率（%），连续变量

### 核心解释变量
- digital_score：企业数字化能力指数（0-100），连续变量

### 控制变量
- firm_age_years：企业成立年限
- employees：员工人数
- rd_intensity_pct：研发投入强度（%）
- marketing_intensity_pct：营销投入强度（%）
- manager_edu_years：管理者受教育年限
- export_dummy：是否出口（1=是，0=否）
- financing_constraint：融资约束程度（1-5，有序变量按连续近似处理）
- industry：行业分类（5 类，生成 4 个虚拟变量，以制造业为基准组）
- region：区域分类（4 类，生成 3 个虚拟变量，以东部为基准组）

### 可选描述变量
- labor_productivity：人均产出指数，仅描述性统计使用

## 3. 推荐主模型

- 模型名称：多元 OLS 回归 + 稳健标准误（HC1）
- 模型公式：

$$revenue\_growth\_pct_i = \alpha + \beta \cdot digital\_score_i + \gamma' Controls_i + \delta' Industry_i + \theta' Region_i + \varepsilon_i$$

- 选择原因：截面数据 + 连续因变量 + 相关性分析的标准方法
- 数据要求：截面数据，因变量连续，样本量 180（自由度充足）
- 诊断要求：VIF 检查多重共线性；Breusch-Pagan 检查异方差；残差正态性检查
- 解释边界：仅支持相关关系，不支持因果解释

## 4. 可选扩展分析

1. **稳健性检验一**：加入/不加入行业和区域虚拟变量，对比 $\beta$ 稳定性
2. **稳健性检验二**：对 employees 取对数后重估
3. **稳健性检验三**：剔除 revenue_growth_pct 极端值（|值| > 3σ）后重估
4. **异质性分析**：按行业分组回归，比较 $\beta$ 差异
5. **异质性分析**：按区域分组回归，比较 $\beta$ 差异

## 5. 不建议做的分析

| 不建议方法 | 原因 |
|---|---|
| DID/事件研究 | 无政策冲击、无处理组/对照组、无时间维度 |
| 面板固定效应/随机效应 | 非面板数据 |
| 工具变量回归 | 无工具变量 |
| DEA 效率评价 | 非多投入多产出结构，研究目标非效率评价 |
| 因果推断表述 | 数据不支持因果识别 |
| 系统GMM | 非动态面板数据 |

## 6. 各章论点提纲

### 引言（800-1000 字）
1. Hook：数字经济时代中小企业数字化转型成为政策热点
2. Research Question：企业数字化能力与营业收入增长率之间是否存在显著相关性
3. Literature 概括：已有研究主要关注大型企业数字化，对中小企业截面样本关注不足
4. Gap：缺乏基于截面数据的中小企业数字化能力与经营绩效相关性研究
5. Contribution：(1) 聚焦中小企业样本；(2) 构建数字化能力指数作为核心解释变量；(3) 控制多维度因素
6. Roadmap：后文结构安排

### 文献综述（1000-1200 字）
1. 数字化转型与企业发展：理论框架与主要结论
2. 数字化能力测度：不同指标体系和方法
3. 中小企业数字化：特殊性与挑战
4. 现有研究不足：样本偏大企业、方法偏面板、缺乏截面相关性分析

### 研究设计（1200-1500 字）
1. 数据来源：180 家中小企业截面数据说明
2. 变量定义：被解释变量、核心解释变量、控制变量的选取理由
3. 模型设定：OLS 模型公式及各参数含义
4. 预期结果：基于理论和文献预期 β 方向

### 实证分析（2500-3000 字）
1. 描述性统计：各变量分布特征、行业/区域分布
2. 相关系数矩阵：主要变量间的相关性初步观察
3. 基准回归：逐步加入控制变量的 OLS 结果
4. 稳健性检验：替换变量处理方式、剔除极端值
5. 异质性分析：按行业和区域分组回归

### 结论（700-800 字）
1. 主要发现总结：数字化能力与营收增长率存在显著正相关
2. 管理启示：对中小企业数字化投资的参考价值
3. 研究局限：截面数据无法识别因果、样本量有限、未控制时间效应
4. 未来方向：面板数据追踪、因果识别策略
