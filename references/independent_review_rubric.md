# AI 味评分细则

本文件定义独立审稿人评估论文 AI 味程度的评分标准。共 4 个维度、16 项指标，每项 0-5 分，总分 0-100 分。

---

## 评分总览

| 维度 | 指标数 | 满分 |
|------|--------|------|
| 词汇与表达 | 5 | 25 |
| 句式与结构 | 5 | 25 |
| 分析深度 | 5 | 25 |
| 整体感 | 5 | 25 |
| **总计** | **16** | **100** |

### 安全阈值

| 分数区间 | 判定 | 说明 |
|---------|------|------|
| 0-29 | 安全 | 读起来像人写的，无明显 AI 痕迹 |
| 30-50 | 需修改 | 有明显 AI 痕迹，需要针对性修改 |
| 50-70 | AI 味重 | 多处 AI 典型特征，需要大改 |
| 70+ | 严重 AI 味 | 基本判定为 AI 生成 |

---

## 维度 1：词汇与表达（25 分）

### 1.1 学术黑话（0-5 分）

检查是否使用了经管类 AI 高频黑话：机制、耦合、协同、赋能、抓手、闭环、底层逻辑、韧性、生态、沉淀。

| 分数 | 判定标准 |
|------|---------|
| 0 | 全文未出现任何黑话 |
| 1 | 出现 1-2 次，但上下文可接受 |
| 2 | 出现 3-4 次，部分可替换 |
| 3 | 出现 5-6 次，明显影响阅读体验 |
| 4 | 出现 7-8 次，多处需替换 |
| 5 | 出现 9 次以上，充斥黑话 |

### 1.2 四字套话（0-5 分）

检查是否使用了：深入探讨、全面分析、显著提升、不可忽视、具有重要意义、日益增长、引起了广泛关注、不容忽视、起到关键作用、日趋完善、不断深化。

| 分数 | 判定标准 |
|------|---------|
| 0 | 全文未出现四字套话 |
| 1 | 出现 1-2 处 |
| 2 | 出现 3-4 处 |
| 3 | 出现 5-6 处 |
| 4 | 出现 7-8 处 |
| 5 | 出现 9 处以上 |

### 1.3 连接词滥用（0-5 分）

检查以下连接词的使用频率：然而、此外、与此同时、综上所述、值得注意的是、换言之、不仅...而且、因此（过度使用）、由此可见、具体而言、总体来看。

| 分数 | 判定标准 |
|------|---------|
| 0 | 连接词使用自然，频率合理（每千字 ≤ 2 个） |
| 1 | 略多（每千字 3-4 个） |
| 2 | 较多（每千字 5-6 个） |
| 3 | 很多（每千字 7-8 个），部分可删 |
| 4 | 过多（每千字 9-10 个），严重影响自然度 |
| 5 | 极多（每千字 10+），几乎每段都有 |

### 1.4 模糊表述（0-5 分）

检查是否使用了：相关研究表明、大量文献、一定程度上、某种程度上、较为显著、可能存在、一定程度上、相关分析表明。

| 分数 | 判定标准 |
|------|---------|
| 0 | 全文没有模糊表述，都有具体指向 |
| 1 | 1-2 处模糊，基本可接受 |
| 2 | 3-4 处模糊 |
| 3 | 5-6 处模糊，影响论证力度 |
| 4 | 7-8 处模糊，论证空泛 |
| 5 | 9 处以上，大量空话 |

### 1.5 政策空话（0-5 分）

检查政策建议部分是否使用了：加强政策支持、完善制度建设、提高质量发展、推动高质量发展、深化体制改革、优化发展环境、构建新格局。

| 分数 | 判定标准 |
|------|---------|
| 0 | 政策建议具体，每条都对应实证结果 |
| 1 | 1 条空泛建议 |
| 2 | 2 条空泛建议 |
| 3 | 3 条空泛建议，部分建议与实证脱节 |
| 4 | 4 条空泛建议，大多数建议泛泛而谈 |
| 5 | 全部是空泛建议，与实证结果无对应 |

---

## 维度 2：句式与结构（25 分）

### 2.1 列表式写作（0-5 分）

检查是否出现"第一，...第二，...第三，...""一是...二是...三是...""首先...其次...最后..."的列表结构。

| 分数 | 判定标准 |
|------|---------|
| 0 | 全文没有列表式段落 |
| 1 | 1-2 处列表式，但内容本身适合分点 |
| 2 | 3-4 处列表式 |
| 3 | 5-6 处列表式，开始影响阅读体验 |
| 4 | 7-8 处列表式，多处像在写提纲 |
| 5 | 几乎每段都是列表式 |

### 2.2 缺乏主语（0-5 分）

检查连续无主语句的数量。AI 经常写出"促进了...提升了...推动了..."这种无主语句子。

| 分数 | 判定标准 |
|------|---------|
| 0 | 每句都有明确主语 |
| 1 | 1-2 处省略主语但上下文可推断 |
| 2 | 3-4 处省略主语 |
| 3 | 5-6 处无主语，部分句子读起来像提纲 |
| 4 | 7-8 处无主语，大量句子缺乏主语 |
| 5 | 连续 3 句以上无主语出现多次 |

### 2.3 "的"字堆砌（0-5 分）

检查是否存在"XX 的 YY 的 ZZ 的 WW"这种多重"的"字结构。

| 分数 | 判定标准 |
|------|---------|
| 0 | 没有明显堆砌 |
| 1 | 1-2 处轻微堆砌 |
| 2 | 3-4 处堆砌 |
| 3 | 5-6 处堆砌，部分句子冗长 |
| 4 | 7-8 处堆砌，句子臃肿 |
| 5 | 大量堆砌，严重影响可读性 |

### 2.4 段落对称（0-5 分）

检查段落长度和结构是否过于整齐划一。AI 生成的段落往往都是 4-5 句，结构雷同。

| 分数 | 判定标准 |
|------|---------|
| 0 | 段落长短交错，结构有变化 |
| 1 | 多数段落有变化，1-2 处对称 |
| 2 | 部分段落过于对称 |
| 3 | 大量段落长度和结构相似 |
| 4 | 几乎所有段落结构雷同 |
| 5 | 每段都是 4-5 句，主题句+论据+总结 |

### 2.5 被动句过多（0-5 分）

检查被动句的使用频率。AI 倾向于用"被...""受...影响"等被动表达。

| 分数 | 判定标准 |
|------|---------|
| 0 | 几乎没有被动句，都以主动语态表达 |
| 1 | 1-2 处被动句 |
| 2 | 3-5 处被动句 |
| 3 | 6-8 处被动句 |
| 4 | 9-12 处被动句 |
| 5 | 大量被动句，文章缺乏行动感 |

---

## 维度 3：分析深度（25 分）

### 3.1 只描述不解释（0-5 分）

检查是否只报告数字而不解释原因。

| 分数 | 判定标准 |
|------|---------|
| 0 | 每个重要发现都有解释或讨论 |
| 1 | 1 处只描述不解释 |
| 2 | 2-3 处只描述不解释 |
| 3 | 4-5 处只描述不解释 |
| 4 | 6-8 处只描述不解释 |
| 5 | 几乎全是数字罗列，没有解释 |

### 3.2 堆砌统计量（0-5 分）

检查是否在正文中重复表格中已有的所有数字。

| 分数 | 判定标准 |
|------|---------|
| 0 | 正文只强调关键数字，不重复表格 |
| 1 | 1-2 处堆砌 |
| 2 | 3-4 处堆砌 |
| 3 | 5-6 处堆砌 |
| 4 | 7-8 处堆砌 |
| 5 | 正文中逐行朗读表格数据 |

### 3.3 缺乏意外感（0-5 分）

检查是否所有分析都是"结果表明...与预期一致""这与已有研究一致"这种四平八稳的写法。

| 分数 | 判定标准 |
|------|---------|
| 0 | 有反直觉发现、有意外感、有"这可能是因为"的解释 |
| 1 | 基本有意外感，1-2 处过于四平八稳 |
| 2 | 部分有意外感，3-4 处太平稳 |
| 3 | 多数分析都是"与预期一致" |
| 4 | 几乎没有意外感 |
| 5 | 完全四平八稳，像在写教科书而非研究论文 |

### 3.4 过度概括（0-5 分）

检查是否存在把单一发现推广为普适结论的倾向。

| 分数 | 判定标准 |
|------|---------|
| 0 | 结论措辞谨慎，明确说明研究边界 |
| 1 | 1 处过度概括 |
| 2 | 2-3 处过度概括 |
| 3 | 4-5 处过度概括 |
| 4 | 6-8 处过度概括 |
| 5 | 结论严重夸大，远超实证结果支撑范围 |

### 3.5 结论夸大（0-5 分）

专门检查结论部分是否出现"填补了空白""边际贡献""理论创新""实践启示"等发表级论文套话，或把效率排名写成绝对实力。

| 分数 | 判定标准 |
|------|---------|
| 0 | 结论务实，无夸大 |
| 1 | 1 处轻微夸大 |
| 2 | 2-3 处夸大 |
| 3 | 4-5 处夸大 |
| 4 | 结论部分严重夸大 |
| 5 | 结论与实证结果严重脱节 |

---

## 维度 4：整体感（25 分）

### 4.1 总-分-总八股（0-5 分）

检查是否每个段落都是"主题句 + 3 个论据 + 总结句"的八股结构。

| 分数 | 判定标准 |
|------|---------|
| 0 | 段落结构多样，没有明显的八股感 |
| 1 | 1-2 个段落有八股感 |
| 2 | 3-4 个段落有八股感 |
| 3 | 5-7 个段落有八股感 |
| 4 | 8-10 个段落有八股感 |
| 5 | 几乎每个段落都是总-分-总 |

### 4.2 三段并列（0-5 分）

检查是否频繁出现"三个并列"结构（三个方面、三个层次、三条建议）。

| 分数 | 判定标准 |
|------|---------|
| 0 | 没有明显的三段并列 |
| 1 | 1 处三段并列但内容本身适合 |
| 2 | 2 处三段并列 |
| 3 | 3-4 处三段并列 |
| 4 | 5-6 处三段并列 |
| 5 | 几乎所有分析都是"三"的倍数 |

### 4.3 每段结构雷同（0-5 分）

检查各段落的起句方式和衔接方式是否单一。

| 分数 | 判定标准 |
|------|---------|
| 0 | 段落起句方式多样（有引用开头的、有数据开头的、有转折开头的） |
| 1 | 多数段落起句方式不同，1-2 处雷同 |
| 2 | 部分段落起句方式相同 |
| 3 | 多段落起句方式相同（如都以"从表X可以看出"开头） |
| 4 | 大量段落起句方式相同 |
| 5 | 段落之间几乎可以互换而不影响阅读 |

### 4.4 引号/破折号过多（0-5 分）

检查非必要的引号和破折号数量。AI 喜欢给关键词加引号、用破折号做补充说明。

| 分数 | 判定标准 |
|------|---------|
| 0 | 引号仅用于直接引用，破折号每千字 ≤ 1 个 |
| 1 | 1-2 处非必要引号或破折号 |
| 2 | 3-4 处非必要引号或破折号 |
| 3 | 5-6 处非必要引号或破折号 |
| 4 | 7-8 处非必要引号或破折号 |
| 5 | 大量非必要引号和破折号 |

### 4.5 学术腔（0-5 分）

综合检查论文是否过度使用学术腔调，与课程论文的定位不符。

| 分数 | 判定标准 |
|------|---------|
| 0 | 语言平实，符合课程论文定位 |
| 1 | 偶尔偏学术腔，整体可接受 |
| 2 | 部分段落学术腔较重 |
| 3 | 多处学术腔，与课程论文定位不符 |
| 4 | 全文学术腔浓厚 |
| 5 | 像在写期刊投稿而非课程论文 |

---

## 评分计算

```
总分 = 维度1得分 + 维度2得分 + 维度3得分 + 维度4得分
```

每个维度的得分 = 该维度下 5 项指标的得分之和。

**安全判定**：总分 < 30 为安全。
