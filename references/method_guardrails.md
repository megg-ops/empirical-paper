# Method Guardrails

本文件定义经管类课程论文中通用的方法红线。modeler_agent 在 Stage 2 设计模型时必须遵守。不偏袒任何单一方法，不默认推荐某一模型。

## 1. 模型-数据不匹配

以下情况为 BLOCKER：

- 截面数据使用面板模型（FE/RE/DID）且没有面板结构；
- 面板数据使用纯截面方法且不解释个体异质性；
- 没有政策冲击、处理组/对照组、时间前后，使用 DID；
- 没有明确断点和运行变量，使用 RDD；
- 没有工具变量，使用 IV/2SLS；
- 非面板数据使用固定效应模型；
- 样本期极短（T<5）使用复杂时间序列模型；
- DMU 数量严重不足（投入产出变量数 × 3 以上）仍使用 DEA。

## 2. 因变量类型不匹配

以下情况为 BLOCKER：

- 因变量不是二元变量，使用 Logit/Probit；
- 因变量不是计数变量，使用 Poisson/Negative Binomial；
- 因变量不是有序离散变量，使用 Ordered Logit/Ordered Probit；
- 因变量没有截断/删失机制，使用 Tobit；
- 因变量不是比例/分数，但使用 Fractional Logit/Beta 回归而不说明理由；
- 效率评价模型（DEA/SFA）的产出不是非负连续量。

## 3. 识别条件缺失

以下情况为 BLOCKER：

- 声称因果识别，但没有任何识别策略（IV/DID/RDD/FE+严格外生性/匹配）；
- 使用 DID 但不讨论平行趋势假设；
- 使用 RDD 但不讨论断点操纵和带宽敏感性；
- 使用 IV 但不解释工具变量的相关性和外生性；
- 使用 GMM 但不报告 AR 检验和 Hansen/Sargan 检验。

## 4. 因果解释越界

以下情况为 BLOCKER：

- 使用 OLS/相关分析/描述统计，但结论中使用"导致""因果效应""政策效应""显著促进""显著抑制"等强因果表述；
- 效率评价模型（DEA/SFA）结论中写因果解释；
- 综合评价/指数构建模型结论中写因果解释；
- 预测模型结论中写因果解释；
- 使用 FE/RE 但不满足严格外生性，结论中写强因果。

**允许的表述**（非因果模型）：

- "与...显著相关"
- "与...存在显著关联"
- "在控制相关变量后，X 与 Y 的关系仍然显著"
- "回归结果显示二者具有统计相关性"
- "方向与理论预期一致"

**禁止的表述**（非因果模型）：

- "导致"
- "因果效应"
- "政策效应"
- "显著促进/显著抑制"
- "使得"
- "提升了/降低了"（除非模型支持因果识别）

## 5. 高级模型数据条件不足

以下情况为 WARN 或 BLOCKER：

- 系统GMM：T 短 N 大但工具变量过多，Hansen 检验不可靠 → WARN；不报告 AR 和 Hansen → BLOCKER；
- 合成控制法：处理组只有 1 个、对照组太少 → WARN；
- 事件研究：政策时点差异大但不说明可比性 → WARN；
- PSM：平衡性检验未通过 → BLOCKER；
- Heckman：没有明确的选择机制说明 → WARN。

## 6. 效率评价/综合评价特殊红线

- DEA/SFA 效率值是相对效率，不得写"绝对绩效排名"；
- 权重（熵权/AHP/CRITIC）不是因果效应，不得写"某指标对综合得分有显著影响"；
- 效率评价通常不支持因果解释，二阶段回归需谨慎；
- 综合评价排名对指标选择和标准化方式敏感，建议做稳健性检验。

## 7. 结论边界声明

model_plan.md 必须明确：

- 是否支持因果解释；
- 允许使用的表述；
- 禁止使用的表述；
- 模型的主要限制。

writer_agent 必须遵守此解释边界。reviewer_agent 必须复核。
