# Model Selection Tree

本文件用于 Stage 2 modeler_agent 的模型选择。modeler 必须先根据数据结构、因变量类型、研究问题和识别条件在本树中定位，再生成模型方案。不得跳过本树直接写公式。

## 0. 总原则

模型选择顺序：

1. 先判断研究目标：描述/相关性分析/效率评价/综合评价/政策评估/机制检验/预测；
2. 再判断数据结构：截面、时间序列、面板、分组截面、事件冲击数据；
3. 再判断因变量类型：连续、二元、多分类、有序、计数、比例、截断/删失、效率值、指数值；
4. 再判断识别条件：是否有政策冲击、处理组/对照组、断点、工具变量、面板固定效应、内生性来源；
5. 最后推荐候选模型集，并说明不推荐模型。

不得因为某个方法"常见"就默认使用。模型必须服务研究问题和数据结构。

---

## 1. 研究目标路由

### 1.1 影响因素/相关性分析

适用问题：
- X 与 Y 是否相关；
- 某些因素是否与结果变量显著关联；
- 不强调严格因果识别。

候选模型：
- 截面 + 连续 Y：OLS；
- 面板 + 连续 Y：FE / RE / 双向固定效应；
- 二元 Y：Logit / Probit；
- 计数 Y：Poisson / Negative Binomial；
- 比例 Y：Fractional Logit / Beta 回归（课程论文可简化说明）；
- 截断/删失 Y：Tobit。

风险：
- 不得写强因果结论；
- 若存在明显反向因果或遗漏变量，应声明限制或换识别策略。

---

### 1.2 政策冲击/处理效应评估

适用问题：
- 有明确政策、事件、制度变化；
- 有冲击前后；
- 有处理组和对照组，或明确断点。

候选模型：
- 双期 DID；
- 多期 DID；
- 事件研究；
- RDD；
- PSM-DID；
- 合成控制法（样本条件允许时）。

必要条件：
- DID：Treat、Post、Treat×Post；
- 多期 DID：政策时点差异、事件时间变量；
- RDD：明确断点和运行变量；
- PSM：处理组/对照组可比，需平衡性检验。

风险：
- 没有政策冲击不得硬做 DID；
- 没有处理组/对照组不得硬做 DID；
- DID 必须讨论平行趋势；
- RDD 必须讨论断点操纵和带宽敏感性。

---

### 1.3 机制检验/中介效应/调节效应

适用问题：
- X 通过 M 影响 Y；
- Z 改变 X 对 Y 的作用强度。

候选模型：
- 中介效应模型；
- 交互项模型；
- 分组回归；
- 结构方程模型（课程论文可选，不默认）。

风险：
- 中介效应不能自动证明因果链；
- 交互项必须解释边际效应；
- 不得只凭显著性堆机制故事。

---

### 1.4 效率评价

适用问题：
- 多投入、多产出；
- 评价相对效率；
- 不以因果识别为主要目标。

候选模型：
- CCR-DEA；
- BCC-DEA；
- 超效率 DEA；
- SBM；
- 三阶段 DEA；
- Malmquist 指数；
- Bootstrap DEA。

必要条件：
- 明确 DMU；
- 投入/产出变量方向合理；
- DMU 数量满足经验要求；
- 三阶段 DEA 需要环境变量；
- Malmquist 需要足够时间维度。

风险：
- DEA 是相对效率，不是绝对绩效；
- BCC 得 PTE，CCR 得 TE，SE=TE/PTE；
- 三阶段 DEA 的第二阶段若不用 SFA，必须声明替代；
- 效率评价通常不支持因果解释。

---

### 1.5 综合评价/指数构建

适用问题：
- 多指标综合评分；
- 构建区域/企业/行业发展水平指数；
- 排名或分层。

候选模型：
- 熵权法；
- TOPSIS；
- PCA；
- 因子分析；
- AHP-熵权组合；
- CRITIC。

风险：
- 权重不是因果效应；
- 排名对指标选择和标准化方式敏感；
- 必须说明正向/负向指标处理；
- 建议做权重或指标替换稳健性检验。

---

### 1.6 预测任务

适用问题：
- 预测 Y；
- 分类或回归预测；
- 重点是预测性能，不是解释机制。

候选模型：
- 线性回归 / Ridge / Lasso；
- Random Forest；
- XGBoost / LightGBM；
- Logistic Regression；
- 时间序列 ARIMA / VAR / LSTM（视数据而定）。

风险：
- 预测模型不能直接解释因果；
- 必须区分训练集/测试集；
- 需要报告预测指标；
- 课程论文若偏实证解释，不建议过度黑箱化。

---

## 2. 数据结构路由

### 2.1 截面数据

连续 Y：
- 基础模型：OLS；
- 异方差风险：稳健标准误；
- 内生性明显：IV / 2SLS；
- 二元 Y：Logit / Probit；
- 计数 Y：Poisson / Negative Binomial；
- 有序 Y：Ordered Logit / Ordered Probit。

不推荐：
- 没有时间维度时不做 FE/DID；
- 没有政策冲击时不做 DID；
- 没有工具变量时不做 IV。

---

### 2.2 面板数据

连续 Y：
- 基础模型：FE / RE / 双向固定效应；
- 是否选 FE/RE：Hausman 检验或理论判断；
- 有共同时间冲击：加入时间固定效应；
- 标准误：聚类稳健标准误优先。

政策冲击：
- DID / 多期 DID / 事件研究。

动态关系：
- 滞后因变量明显时，可考虑动态面板；
- T 短、N 大时可考虑系统 GMM；
- 课程论文中系统 GMM 应谨慎使用。

不推荐：
- 面板数据直接 pooled OLS 但不解释个体异质性；
- 没有冲击却硬做 DID；
- T 很短时过度解释长期趋势。

---

### 2.3 时间序列数据

适用：
- 单一对象随时间变化；
- 关注趋势、预测或动态关系。

候选模型：
- ARIMA；
- VAR；
- VECM；
- 单位根和协整检验；
- 结构突变检验。

风险：
- 样本期太短不适合复杂时间序列模型；
- 非平稳变量不能直接 OLS；
- 不得把趋势相关误写为因果。

---

### 2.4 多投入多产出 DMU 数据

候选：
- DEA / SBM / 三阶段 DEA / Malmquist。

必要条件：
- DMU 数量足够；
- 投入产出变量非负；
- 投入产出方向明确；
- 不要混淆效率评价和回归因果分析。

---

## 3. 因变量类型路由

| 因变量类型 | 推荐模型 | 风险提示 |
|---|---|---|
| 连续变量 | OLS / FE / RE / DID | 注意内生性、异方差、固定效应 |
| 二元变量 | Logit / Probit / LPM | Logit 系数不能直接解释为边际效应 |
| 多分类变量 | Multinomial Logit | 需说明基准组 |
| 有序变量 | Ordered Logit / Ordered Probit | 需说明比例优势假设或局限 |
| 计数变量 | Poisson / Negative Binomial | 注意过度离散 |
| 比例变量 | Fractional Logit / Beta 回归 | OLS 可能越界 |
| 截断/删失变量 | Tobit | 需说明删失机制 |
| 效率值 | Tobit / Fractional model / 二阶段回归 | DEA 二阶段回归需谨慎 |
| 综合指数 | OLS / FE / 分组比较 | 指数构建方式需稳健性 |

---

## 4. 内生性来源路由

### 4.1 无明显内生性

可使用：
- OLS / FE / RE；
- 控制变量；
- 稳健标准误。

结论边界：
- 只能写相关关系或条件相关。

### 4.2 遗漏变量

可使用：
- 固定效应；
- 更多控制变量；
- IV；
- DID；
- 匹配方法。

### 4.3 反向因果

可使用：
- IV；
- 滞后解释变量；
- DID；
- 自然实验。

### 4.4 选择偏误

可使用：
- PSM；
- Heckman；
- DID / PSM-DID。

### 4.5 动态内生性

可使用：
- 动态面板；
- Difference GMM / System GMM。

风险：
- 工具变量必须解释相关性和外生性；
- GMM 需要报告 AR 检验和 Hansen/Sargan；
- 课程论文中若数据条件不足，应优先保守说明局限。

---

## 5. 输出要求

modeler_agent 使用本树后，必须输出：

1. 数据结构定位；
2. 因变量类型定位；
3. 识别条件定位；
4. 候选模型集；
5. 最终推荐模型；
6. 不推荐模型及原因；
7. 方法-数据匹配风险；
8. 结论解释边界。
