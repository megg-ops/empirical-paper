# Word 输出格式规则

本文件仅在 `output_format=docx` 时读取。

## Word 格式后处理原则

pandoc 的 `--reference-doc` 只继承模板的样式定义（style-level），无法读取模板中的：
1. **文字说明**（如"一级标题用四号楷体"）— 格式规则写在模板正文里
2. **run 级别格式**（如每段文字手动设的黑体、楷体、宋体）— 格式刷上去的，不在样式定义中

因此 pandoc 转换后必须用 python-docx 做格式后处理。

## 优先级

格式规则优先级为：

```text
模板文字说明 > skill 默认规则 > Word 样式定义 > 模板 run 级格式
```

模板中明确写出的文字说明优先级最高，例如：

- 一级标题用三号黑体，居中；
- 正文小四宋体，首行缩进 2 字符；
- 表格使用三线表；
- 图题居中，五号宋体。

## 后处理修复顺序

1. **修正标题层级**：pandoc 把 `#` → H1（论文标题）、`##` → H2（章节）。但模板中论文标题通常不是 Heading 样式，章节才是 H1。需将论文标题改为 Normal + 模板指定格式，`##` → H1，`###` → H2。当模板中不存在 H3 样式时，pandoc 会回退为 Normal，需按内容模式（如"（一）"开头）识别并修正
2. **修正标签/标题字体**：按模板文字说明设置摘要标签、关键词标签、章节标题的字体字号（pandoc 只加了 bold，没有设中文字体）
3. **修正正文 run 字体**：英文/数字用 Times New Roman（默认规则），中文字体按模板指定
4. **修正图表标题**：按模板指定字号（默认居中，表标题在上，图标题在下）
5. **修正表格为三线表**：pandoc 默认生成全边框表格，必须改为三线表（默认规则）
6. **修正参考文献**：按模板指定字体，序号 [1] [2] 格式（默认规则）

## 默认格式规则

即使没有 Word 模板，以下格式规则仍应默认应用：

| 元素 | 默认格式 |
|------|----------|
| 正文段落 | 首行缩进 2 字符 |
| 英文/数字字体 | Times New Roman |
| 表格 | 三线表 |
| 表标题 | 居中，位于表格上方 |
| 图标题 | 居中，位于图片下方 |
| 参考文献 | 序号 [1] [2]... 按出现顺序排列 |

**标题序号规范**（经管类课程论文默认）：

文中标题序号按"一、""（一）""1.""（1）""第一"或"首先"顺序排列，一般不用"①"号，以区分脚注。根据文章叙述层次，不需要全用时，可适当减少，但不可反顺序使用。"一"后加"、"号，"1"后加"."；（一）、（1）不加任何标点，"第一"、"首先"后面均要加"，"号。

**注意**：中文字体（宋体/楷体/黑体等）、字号（16pt/14pt/10.5pt等）、标题对齐方式等由模板文字说明指定，不属于默认规则。有模板时优先级为：模板文字说明 > 默认规则 > 模板样式定义 > 模板 run 级别格式。

## 模板解析要求

如果用户上传 Word 模板，Stage 0 必须运行：

```bash
python scripts/extract_word_template_rules.py \
  --template <template.docx> \
  --output <workspace>/00_intake/output/template_rules.json \
  --text-output <workspace>/00_intake/output/template_text.md
```

如果模板存在但 `template_rules.json` 缺失，Stage 5 不得继续生成最终 Word。

## 图表规则

Word 输出中，writer 应优先使用：

```markdown
[FIGURE: fig_01]

[TABLE: table_01]
```

Stage 5 由 `gen_docx.py` 根据 `assets_manifest.json` 插入真实图表。

最终 docx 不得残留 `[FIGURE: ...]` 或 `[TABLE: ...]` 占位符。
