# 中文论文 AI 痕迹规避规则

本文件用于约束 writer_agent、reviewer_agent 和 expert_reviewer_agent 的中文论文写作与审查。

目标不是把论文改得口语化，而是减少模板化、空泛化和机械化表达，使文本更接近经管类学生认真写出的课程论文。

本文件中的规则分为三类：

- HARD：原则上禁止，出现后必须改；
- SOFT：尽量避免，视语境调整；
- ALLOW：允许使用，但需要有具体内容支撑。

去 AI 味不得牺牲统计准确性、方法一致性、数字一致性和因果解释边界。

## 称呼禁用规则

### HARD 禁用

正文中禁止使用：

- 读者
- 我们
- 大家
- 笔者认为
- 可以看到我们
- 我们可以看到
- 不难看出
- 大家可以发现

### 推荐替换

| 禁用表达 | 推荐表达 |
|---|---|
| 我们可以看到 | 表 X 显示 / 结果显示 |
| 读者可以发现 | 结果显示 / 从表 X 可见 |
| 我们认为 | 本文认为 / 本文将其解释为 |
| 不难看出 | 结果表明 / 该结果显示 |
| 大家可以看到 | 表 X 显示 |

### 规则

课程论文正文应使用"本文""本研究""回归结果""表 X""模型 X"等客观主语，不使用与读者直接对话的表达。

## 一、符号类 AI 痕迹

### 显著性标记

AI 倾向在正文括号内嵌显著性标记，这是明显的 AI 痕迹。

| 反例 | 正例 |
|------|------|
| 产业结构水平的系数为8.07（1%显著） | 产业结构水平对投入松弛有显著正向影响 |
| 教育财政支持强度的系数为-13.00（1%显著） | 教育财政支持强度的系数显著为负 |
| 经济发展水平的系数为0.31（5%显著），方向为正 | 经济发展水平的系数显著为正 |

**规则**：正文用叙述句描述显著性方向，显著性星号仅在表格中使用。表注用 `$^{***}$p<0.01，$^{**}$p<0.05，$^{*}$p<0.1`。

### 箭头

AI 喜欢用箭头表示因果或流程，这在学术论文中不规范。

| 反例 | 正例 |
|------|------|
| 数字化转型 → 企业绩效提升 | 数字化转型促进了企业绩效提升 |
| A → B → C | A 通过 B 影响 C |
| 研究发现：X → Y | 研究发现 X 与 Y 正相关 |

**规则**：正文中禁止使用箭头符号。流程图中的箭头除外。

### 引号

AI 倾向于给关键词加引号以"强调"，这是多余的。

| 反例 | 正例 |
|------|------|
| "数字化转型"是当前热点 | 数字化转型是当前热点 |
| 企业通过"赋能"实现增长 | 企业通过技术升级实现增长 |
| "双重差分"方法 | 双重差分方法 |

**规则**：除非是直接引用他人原文，否则不给普通术语加引号。

### 破折号

AI 喜欢用破折号做补充说明，但中文论文中应少用。

| 反例 | 正例 |
|------|------|
| 数字化转型——作为新兴战略——对企业绩效有显著影响 | 数字化转型作为新兴战略，对企业绩效有显著影响 |
| 该方法——即双重差分法——能够控制不可观测因素 | 该方法（双重差分法）能够控制不可观测因素 |

**规则**：用逗号或括号替代破折号。每千字最多 1 个破折号。

### 省略号和感叹号

学术论文中不应出现。

| 反例 | 正例 |
|------|------|
| 结果表明…… | 结果表明 |
| 这一发现很有意义！ | 这一发现具有一定意义。 |

## 二、词汇类 AI 痕迹

### 慎用词

以下词语不是绝对禁止，但不得空泛使用：

| 慎用词 | 可接受用法 | 不接受用法 |
|---|---|---|
| 机制 | 机制检验、传导机制，并明确变量和路径 | 泛泛写"形成长效机制" |
| 协同 | 明确两个变量、部门或活动如何共同作用 | 泛泛写"协同发展" |
| 赋能 | 原则上少用，若使用需说明具体技术作用 | 数字化赋能高质量发展 |
| 生态 | 明确指产业生态、创新生态或商业生态 | 泛泛写"构建良好生态" |
| 韧性 | 明确指抗风险能力或恢复能力 | 泛泛写"增强发展韧性" |

规则：若无法说明具体对象、路径或变量关系，应直接替换为更具体的表达。

### 四字成语/套话

| 禁用 | 替换为 |
|------|--------|
| 深入探讨 | 分析 / 研究 / 考察 |
| 全面分析 | 从 X 和 Y 两个维度分析 |
| 显著提升 | 提高了 X% / 从 X 增长到 Y |
| 不可忽视 | 值得关注 / 需要重视 |
| 具有重要意义 | 对 X 有直接影响 / 有助于 Y |
| 日益增长 | 从 X 增长到 Y / 年均增长 X% |
| 引起了广泛关注 | 多数文献聚焦于 / 近年研究集中于 |
| 不容忽视 | 需要关注 / 值得注意 |
| 起到关键作用 | 是 X 的主要驱动因素 |
| 提供了有力支撑 | 支持了 X 的结论 / 与 X 一致 |
| 具有重要参考价值 | 为 X 提供了依据 |
| 值得深入研究 | 有待进一步考察 / 可作为后续研究方向 |
| 日趋完善 | 逐步改善 / 不断改进 |
| 不断深化 | 持续推进 / 逐步深入 |

### 过度使用的连接词

每千字最多使用 2 个以下连接词：

| 过度使用 | 替换方式 |
|----------|----------|
| 然而 | 但 / 不过 / 反观 |
| 此外 | 另外 / 同时 |
| 与此同时 | 删除，用句号断开 |
| 综上所述 | 直接说结论 |
| 值得注意的是 | 删除，直接说内容 |
| 换言之 | 也就是说 / 即 |
| 不仅...而且... | 减少使用频率 |
| 因此 | 所以 / 故 |
| 由此可见 | 删除，直接说结论 |
| 具体而言 | 删除，直接展开 |
| 总体来看 | 删除，直接说 |

### 模糊表述

| 模糊 | 具体 |
|------|------|
| 相关研究表明 | XX（20XX）发现 / XX 和 XX（20XX）的研究表明 |
| 大量文献 | XX 篇文献中，XX 篇采用了... |
| 一定程度上 | 在 X 方面 / 在 Y 条件下 |
| 某种程度上 | 删除，直接说具体程度 |
| 较为显著 | 在 5% 水平上显著 / 系数为 X |
| 可能存在 | 删除，直接陈述或给出证据 |

## 三、句式类 AI 痕迹

### 列表式写作

AI 最典型的模式：一个结论句 + 多个并列解释句，像在写要点列表。

**反例**：
> 数字化转型对企业绩效的影响主要体现在三个方面。第一，降低了信息不对称程度。第二，提高了资源配置效率。第三，增强了创新能力。

**问题**：每句话都没有主语，像在列清单，不像在写文章。

**正例**：
> 数字化转型主要通过三个渠道影响企业绩效。在信息层面，数字化工具降低了企业内外部的信息不对称程度；在资源层面，数据驱动的决策提高了资本和人力的配置效率；在创新层面，数字技术为企业提供了新的研发路径和商业模式。

### 主语补全规则

### HARD

不得连续三句以上缺少明确主语。

### 推荐主语

- 本文
- 本研究
- 样本结果
- 描述性统计结果
- 相关系数结果
- 回归结果
- 稳健性检验结果
- 表 X
- 图 X
- 模型 X
- 该结果
- 这一关系
- 这一设定

### 改写规则

错误：

> 采用 OLS 回归方法。控制行业和区域变量。发现数字化能力显著为正。

改写：

> 本文采用 OLS 回归方法，并进一步控制行业和区域变量。回归结果显示，数字化能力系数为正且通过显著性检验。

### 注意

可以使用"本文"补主语，但不要每句都用"本文"。优先根据语境使用"表 X""模型 X""回归结果""描述性统计结果"等更具体的主语。

### "X 的 Y" 堆砌

AI 喜欢用大量"的"字结构，导致句子臃肿。

**反例**：
> 数字化转型背景下的企业绩效提升机制的研究具有重要的理论和实践意义。

**正例**：
> 研究数字化转型如何影响企业绩效，既有理论价值，也有实践意义。

### 被动句过多

AI 倾向于使用被动句，导致文章缺乏主语和行动感。

**反例**：
> 样本被筛选为上市公司数据。缺失值被删除。回归分析被采用。

**正例**：
> 本文选取上市公司数据作为样本。删除缺失值后，最终样本包含 1000 家公司。采用 OLS 回归进行分析。

## 高频模板句

### HARD 避免

正文中尽量不要出现：

- 一个值得关注的现象是
- 值得注意的是
- 需要指出的是
- 不过需要再次强调
- 增强了对……结论的信心
- 这一发现具有重要启示
- 具有重要现实意义
- 为……提供参考
- 第一，……第二，……第三，……
- 一方面，……另一方面，……

### 推荐替换

| 模板句 | 替换方式 |
|---|---|
| 一个值得关注的现象是 | 直接写结果，例如"结果还显示……" |
| 值得注意的是 | 删除，直接进入事实 |
| 不过需要再次强调 | 改为"这里仍需说明"或直接写限制 |
| 增强了对……结论的信心 | 改为"说明该关系在不同设定下保持稳定" |
| 第一，第二，第三 | 改成自然段，或只在模板要求分点时使用 |
| 为……提供参考 | 改为"可作为……的经验依据"或删除 |

## 列表化例外

以下情况允许分点：

- 学校模板明确要求；
- 政策建议部分确实需要分条；
- 研究发现较多且彼此独立；
- 答辩材料或项目说明，而非正式论文正文。

即便允许分点，也应避免每一点都使用相同句式。

反例：

> 第一，……。第二，……。第三，……。

推荐：

> 回归结果首先显示……。分行业结果进一步表明……。稳健性检验则说明……。

## 英文注解规则

### HARD

不要机械使用"中文名词（英文变量名）"格式。

反例：

- 营业收入增长率（revenue_growth_pct）
- 数字化能力指数（digital_score）
- 企业年龄（firm_age）
- 普通最小二乘法（OLS）

推荐：

- 被解释变量为营业收入增长率。
- 核心解释变量为数字化能力指数。
- 企业年龄用于控制企业成立时间差异。
- 本文采用普通最小二乘法进行回归分析。

### 规则

正文优先写变量含义，不主动写代码字段名。

如需说明英文变量名，应集中放在变量说明表、模型公式、公式解释、数据字段说明或代码附录中，不要在正文叙述段落中反复括号注解。

### 允许例外

以下位置可以保留英文变量名：

- 变量说明表；
- 模型公式；
- 公式后的变量解释；
- 数据字段说明；
- 代码附录；
- 用户模板明确要求展示变量名的部分；
- 常用英文缩写第一次出现时，例如"普通最小二乘法，简称 OLS"。

### 检查规则

如果正文叙述段落中出现大量 `中文（english_variable）`，writer_agent 必须改写。

正文优先写变量含义，变量英文名只在需要保证可复现性的位置集中说明。

## 四、段落结构类 AI 痕迹

### 段落过于对称

AI 生成的段落往往长度相近、结构雷同。

**反例**：
> 每段都是 4-5 句，结构都是"主题句 + 3 个论据 + 总结句"。

**正例**：
> 短段（2-3 句）和长段（5-8 句）交替。允许单句成段（强调关键发现时）。段落结构根据内容需要变化。

### "总-分-总" 八股

**反例**：
> [主题句] 本文发现...。[论据1] 首先...。[论据2] 其次...。[论据3] 最后...。[总结句] 综上...。

**正例**：
> 表 2 显示，核心变量系数为正，且在加入控制变量后仍保持显著。该结果可能与样本企业的数字化基础有关。对于行业差异较大的样本，后续分析还需要控制行业因素。

### 并列三段论

AI 特别喜欢"三个并列"的结构。

**反例**：
> 影响机制包括三个方面：一是...；二是...；三是...
> 政策建议如下：第一，...；第二，...；第三，...

**正例**：
> 影响机制主要通过两个渠道发挥作用。其一是...，其二是...。此外，还有一个次要渠道是...
> 政策层面，最紧迫的是...。同时，...也需要关注。

## 五、数字引用规范

### 堆砌统计量

**反例**：
> 效率均值为 0.872，标准差为 0.134，最大值为 1.250，最小值为 0.456，中位数为 0.865。

**正例**：
> 效率均值为 0.87，省际差异较大（标准差 0.13）。北京以 1.25 位居首位，而最低的省份仅为 0.46。

### 表格数据重复

表格已经呈现的数据，正文不需要重复罗列。

**反例**：
> 从表 1 可以看出，北京的效率值为 1.250，上海为 1.180，江苏为 1.090，湖北为 0.960...

**正例**：
> 从表 1 可以看出，东部省份效率普遍高于 1，中西部多数低于 1，呈现明显的梯度特征。

## 六、分析深度规范

### 只描述不解释

**反例**：
> 从表 3 可以看出，核心解释变量的系数为 0.045，在 1% 水平上显著。这说明该变量有正向影响。

**正例**：
> 核心解释变量的系数为 0.045，在 1% 水平上显著。这意味着该变量每增加 1 个标准差，被解释变量平均提高 4.5 个百分点。这一效应在经济意义上也具有重要性。对于样本中位数企业而言，相当于绩效提升约 12%。

### 缺乏"意外感"

**反例**：
> 结果表明，数字普惠金融显著降低了贫困脆弱性。这与已有研究一致。

**正例**：
> 数字普惠金融的减贫效应显著，但出乎意料的是，教育水平的调节作用并不显著。这可能是因为农村地区数字素养普遍较低，教育水平的差异未能转化为数字金融使用的差异。

## 七、学科术语规范

### 首次出现的术语

首次出现的专业术语需要简要解释：

**反例**：
> 本文采用双向固定效应模型。

**正例**：
> 本文采用双向固定效应模型，在控制个体异质性的同时控制时间趋势，以缓解遗漏变量偏误。相比随机效应模型，Hausman 检验在 1% 水平上拒绝了随机效应假设，支持固定效应设定。

### 政策建议部分

避免学术腔和政策空话：

**反例**：
> 建议相关部门加强政策支持力度，促进资源优化配置。
> 构建多元化投入机制，完善绩效评价体系。

**正例**：
> 对效率较高但资源条件不足的中西部省份，中央财政应给予稳定的科研专项支持，而非简单按产出规模分配经费。
> 高校科研评价应降低论文数量权重，增加成果转化和技术转让收入的考核比重。

## Markdown 强调规则

### HARD

正文中不得用 `**...**` 大段加粗。

允许加粗的位置：

- 一级标题、二级标题；
- 摘要、关键词标签；
- 表头；
- 必要的报告标签，如 BLOCKER、PASS。

禁止：

- 用加粗强调普通术语；
- 让加粗跨越整句或整段；
- 出现未闭合的 `**` 或 `__`。

检查规则：

- paper_draft.md 中 `**` 必须成对出现；
- 非标题段落中连续加粗超过 30 个汉字，判定 WARN；
- 连续加粗超过 80 个汉字，判定 BLOCKER。

## 准确性优先

去 AI 味不得改变以下内容：

- 模型名称；
- 变量含义；
- 系数数值；
- 显著性水平；
- 样本量；
- 图表编号；
- 公式含义；
- 因果解释边界。

如果自然表达与统计准确性冲突，优先保留统计准确性。

## 八、综合自检清单

润色时逐项检查：

1. **符号**：正文中是否有箭头（→）、多余的引号、过多的破折号？
2. **词汇**：是否使用了机制、耦合、协同、赋能、抓手等黑话？是否有慎用词空泛使用？
3. **主语**：连续 3 句以上是否都没有主语？
4. **列表感**：是否在写"第一，...第二，...第三，..."的清单？
5. **段落**：所有段落长度是否相近？结构是否雷同？
6. **连接词**：每千字是否超过 2 个"然而/此外/与此同时"？
7. **数字**：是否在重复表格中已有的数据？
8. **分析**：是否只描述了结果而没有解释原因？
9. **引用**：是否有编造的参考文献？
10. **政策**：建议是否空泛、是否可以用更具体的语言表达？
11. **称呼**：是否出现了"读者""我们""大家""不难看出"？
12. **英文注解**：是否在正文段落中大量使用"中文（english_variable）"？
13. **模板句**：是否出现了"值得注意的是""需要指出的是"等高频模板句？
14. **加粗**：是否存在未闭合 `**` 或大段加粗？
15. **准确性**：去 AI 味是否改变了数字、方法、公式或因果边界？
