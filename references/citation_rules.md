# 引用规范

本文件定义经管类课程论文的引用规则。所有 agent 必须遵守。

---

## 红线

1. **禁止编造引用**：不得编造作者、年份、题名、期刊名
2. **禁止伪装未确认文献**：无法确认真实性的文献不得伪装成确定引用
3. **cite 与 bibitem 必须一一对应**：paper 中每个 \cite{} 必须在 thebibliography 中有对应条目

---

## 引用来源优先级

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | 用户提供的 PDF 参考文献 | 最可靠，从中提取真实引用信息 |
| 2 | 用户提供的 References.txt | 已整理的引用列表 |
| 3 | 标准方法文献 | 方法论部分的经典文献（如 Fried 2002、Battese 1995），需确认准确性 |
| 4 | WebSearch 验证的文献 | 通过搜索确认真实存在的文献，标注"已验证" |
| 5 | 未验证文献 | 无法确认的文献，必须标注"[待确认]" |

---

## 从用户 PDF 提取引用信息

当用户提供参考文献 PDF 时：

1. 读取 PDF 提取标题、作者、期刊、年份、卷号、页码
2. 与 References.txt 中的信息交叉验证
3. 如果 PDF 中的信息与 References.txt 不一致，以 PDF 为准
4. 提取后写入 references_used.md，标注来源为"用户上传"

---

## 标准方法文献

skill 不预设特定方法的标准文献清单。方法论文献的引用规则：

1. **用户提供的文献优先**：从用户 PDF 或 References.txt 中提取
2. **补充文献必须验证**：通过 WebSearch 确认真实存在，标注"已验证"
3. **不得编造**：无法确认的文献只能写入"待补充参考文献"

**常见方法类型**（非穷举）：
- 效率评价：DEA、SFA、三阶段 DEA、Malmquist 指数
- 回归分析：OLS、固定效应、随机效应、GMM
- 因果识别：DID、RDD、IV、PSM
- 综合评价：层次分析、熵权法、TOPSIS
- 机器学习：随机森林、XGBoost、神经网络

每种方法的原始文献和经典文献，应由用户在 References.txt 中提供，或由 writer 通过 WebSearch 验证后补充。

---

## 未验证文献处理

当 writer_agent 需要补充用户未提供的文献时：

1. 通过 WebSearch 搜索文献，确认其真实存在
2. 如果搜索成功，写入 references_used.md，标注"已验证"
3. 如果搜索失败或无法确认，写入 references_used.md，标注"[待确认]"
4. 在 paper 中，未验证文献使用以下格式：
   - 正文引用：（作者，年份）[待确认]
   - 参考文献列表：在条目末尾标注"[待确认]"

---

## 引用格式

引用格式由 Stage 2 五项确认中的"引用格式"选项决定。两种格式均可接受：

### 格式 A：交叉引用（传统 LaTeX 方式）

正文用 `\cite{key}`，参考文献列表用 `thebibliography` 环境。

```latex
正文引用：（作者，年份）\cite{key}

参考文献列表：
\begin{thebibliography}{99}
\bibitem{key} 作者.题名[J].刊名,年,卷(期):页码.
\end{thebibliography}
```

### 格式 B：行内格式（无交叉引用）

正文中直接写"姓名等（年份）"，参考文献列表用 `enumerate` 环境。不使用 `\cite{}`/`\bibitem{}`。

```latex
正文引用：中文三人及以上→ 姓名等（年份），英文三人及以上→ Name et al.（year）
          两人→ 姓和姓（年份），一人→ 姓（年份）

参考文献列表：
\section*{参考文献}
\begin{enumerate}[label={[\arabic*]},leftmargin=3em]
\item 作者.题名[J].刊名,年,卷(期):页码.
\end{enumerate}
```

**选择建议**：格式 B 更简单，不依赖 bibtex 编译，适合课程论文。

### GB/T 7714 格式（中文课程论文常用）

**期刊论文**：
```
作者.题名[J].刊名,年,卷(期):起止页码.
```

**专著**：
```
作者.书名[M].出版地:出版社,年.
```

**学位论文**：
```
作者.题名[D].保存地:保存单位,年.
```
